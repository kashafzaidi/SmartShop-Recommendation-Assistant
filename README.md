# 🛍️ SmartShop Recommendation Assistant

An AI-powered product recommendation assistant that helps users discover relevant products based on their search queries and preferences.

## ✨ Features

* 🔎 Smart product search
* 🎯 Relevant product recommendations
* 🛒 Interactive shopping experience
* 💬 Recommendation assistant
* 📱 Responsive user interface

## 🛠️ Tech Stack

* React
* TypeScript
* CSS
* pnpm

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/kashafzaidi67/SmartShop-Recommendation-Assistant.git
```

### Install dependencies

```bash
pnpm install
```

### Run the project

```bash
pnpm dev
```

Then open the local URL shown in your terminal.
